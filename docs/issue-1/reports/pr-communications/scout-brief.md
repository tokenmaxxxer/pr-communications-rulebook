## Category must-bes (Kano)

- A PR plan is built on a **named 4-step process** — Research → Objectives/
  Action → Communication/Programming → Evaluation (RACE, per Marston 1979 /
  Cutlip-Center-Broom lineage; ROPES is the same shape, R-O-P-E-S). Skipping
  the research/objectives step and going straight to messaging is the
  textbook failure mode.
- **Key messages are hierarchical, not a flat list**: one core message +
  supporting messages + proof points, capped at ~3 messages/page, each
  1–3 sentences or <30s spoken. A "key message" with no proof point backing
  it is incomplete by field standard.
- A **written plan has stakeholder analysis** (who, influence/interest,
  channel) as a named section, not folded silently into messaging.
- **Crisis/Q&A prep is pre-approved and cached**, not drafted live: anticipated
  questions + approved answers, reviewed by legal/leadership before the need
  arises — the same discipline whether the trigger is a launch, a crisis, or
  routine external comms.

## Performance axes (what strong examples compete on)

1. **Traceability of message → proof point** — does each key message cite
   the evidence/fact backing it, or is it asserted?
2. **Stakeholder-channel fit** — is the audience segmented with a matched
   channel/frequency, or is it one message blasted everywhere?
3. **Evaluation criteria stated up front** — RACE's "E" step requires success
   criteria defined before send, not measured after the fact.

## Adopt / skip

- **Adopt**: RACE as the phase-1 proposal's named methodology (already a
  natural fit — phase-1 proposal *is* the Research+Objectives stage; phase-2
  delivery *is* the Communication stage; a stated Evaluation criterion belongs
  in the phase-2 record). Adopt the 3-tier key-message hierarchy and
  stakeholder-analysis section as required components. Adopt pre-approved
  Q&A as the risk/Q&A-prep required shape.
- **Skip**: full ROPES vs RACE debate (same shape, redundant to require both);
  skip prescribing specific PR software/tools (out of scope, this is a
  methodology/structure question not a tooling one); skip the "8–15 page"
  length prescription — arbitrary and unenforceable via a plugin gate.

## Segment fit

This role is issue-scoped and PR-artifact-scoped (git repo, GitHub-based
role-handoff contract), not an ongoing brand/comms department — so the plan
scope is per-issue communications, not an annual comms calendar. RACE maps
cleanly onto the phase-1/phase-2 split already imposed by the contract; no
adaptation needed beyond naming it explicitly.
